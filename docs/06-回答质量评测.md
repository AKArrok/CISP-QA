# 06 - 回答层质量评测

检索评测（05-检索测试集评测.md）证明"上下文里有答案页"（holdout 100 题 R5 99%），但最后一步——LLM 生成的答案——此前零测量。本文档建立回答层质量基线与回归工具。

## 1. 评测脚本

`tests/eval_answer_quality.py`，完整跑 `route → rewrite → retrieve → answer` 生产链路（`agents.graph.run`），对每个答案做三层检查：

1. **程序化引用校验**：解析答案末尾【出处】行，核对引用的《文件》第M页是否真的在检索上下文中、是否命中 gold 证据页；
2. **LLM-as-judge**（deepseek-v4-flash，与回答模型 v4-pro 不同模型避免自评偏好）：忠实度 / 要素完整性 / 引用支撑三维 0-2 打分，judge 只看检索上下文与答案，资料无法支撑的具体事实要扣分；
3. **相关性门限误拒统计**：领域内问题被门限拒答即计为误拒。

评测期间 `persist` 节点被替换为空操作，不污染长期记忆库与画像表。支持 `--limit N` 单题数、`--only id1,id2` 指定题集（修复前后 A/B）、`--output` 报告路径。回答与评审均走 DeepSeek（独立额度，100 题全量约 40 分钟——回答模型 v4-pro 是耗时大头）。

## 2. 首轮基线（holdout 100 题）

| 指标 | 分数 |
|------|------|
| 忠实度（满分 2） | 1.79 |
| 要素完整性 | **2.00**（100 题全部满分） |
| 引用支撑 | 1.85 |
| 出处行出现率 | 100% |
| 引用页在检索上下文中 | 99.8% |
| 引用命中 gold 证据页 | **99%** |
| 门限误拒 | **0** |

逐例归因发现三类问题：

1. **"考试记忆点"未标注**（主因，约 10 题）：prompt 规则 3 要求给记忆点提示，但模型补的资料外记忆点没按规则 1 标注"（通用补充）"，评审如实扣分；
2. **过度引用**（8 题）：规则 4 只要求列出来源、未要求"只列真正支撑的"，模型把无关页挂进出处；
3. **转述失真 1 处**：资料原文"财务和会计不能为同一人"被答案写成"会计和出纳"——润色改动了事实细节，judge 抓出（忠实度唯一 0 分）。

## 3. Prompt 修正与 A/B 验证

`agents/prompts.py` ANSWER_SYSTEM 三处收紧：

- 规则 1 增加"转述资料时不得改动具体示例和数字"；
- 规则 3 增加"记忆点/易混淆点必须能从资料推出，推不出的须标注（通用补充）"；
- 规则 4 增加"只列出真正支撑了答案内容的来源，与答案无关的资料不要列"。

对首轮全部 24 个非满分题做同题 A/B（答案由 LLM 重新生成，评审独立）：

| 指标（同 24 题） | 修正前 | 修正后 |
|------|--------|--------|
| 忠实度 | 1.125 | **1.583**（11 题提升 0 题下降） |
| 引用支撑 | 1.375 | **1.667** |
| 忠实度 0 分 | 1 | **0** |
| 要素完整性 | 2.00 | 2.00 |
| 引用命中 gold | 1.00 | 1.00 |

## 4. 回答模型切换 deepseek-v4-flash 的质量验证

成本/延迟优化：回答模型从 v4-pro 切到 v4-flash（`.env LLM_MODEL`），用本脚本全量回归验证（此时 prompt 已含第 3 节修正）：

| 指标（holdout 100 题） | v4-pro（修正前 prompt） | v4-flash（修正后 prompt） |
|------|------|------|
| 忠实度 | 1.79 | **1.79** |
| 要素完整性 | 2.00 | 1.99 |
| 引用支撑 | 1.85 | **1.87** |
| 忠实度 0 分题 | 1 | 2 |
| 引用命中率（gold） | 99% | 96.9% |

flash 平均质量与 pro 持平，成本/延迟降一个量级；代价是偶发的细节失真（2 题：等级测评禁止行为"5 项"说成"6 类"且自相矛盾、RBAC 例句转述污染）。两代模型独立犯同款"财务和会计→会计和出纳"转述错误——是模型训练知识（教材经典例句）对资料转述的污染倾向，prompt 规则 1 的"不得改动具体示例"能压制但不杜绝，已记录为已知限制。

## 5. 已知限制

- 剩余忠实度 1 分题中，约 3 题是"已标注（通用补充）但评审仍扣"——资料外补充对备考是否保留属产品权衡，当前 prompt 倾向保留但要求标注；
- 另约 6 题是模型未完全遵守标注规则（LLM 指令一致性极限），继续加压 prompt 边际收益递减；
- judge 本身是 LLM，单次打分有波动；A/B 结论基于同题对比与 11:0 的提升方向性，非绝对分数；
- 回答与评审同走 DeepSeek，模型升级后应重跑基线。

## 6. 使用

```bash
python tests/eval_answer_quality.py                # 全量 100 题（约 40 分钟）
python tests/eval_answer_quality.py --limit 5      # 冒烟
python tests/eval_answer_quality.py --only id1,id2 --output data/ab.json  # 指定题 A/B
```

改 prompt / 换回答模型后重跑，与 `data/answer_quality_report.json` 基线对比，防止回答层静默劣化。
