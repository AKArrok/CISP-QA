# 切片策略 A/B/C 评测（legacy / fixed / structured）

## 评测设置

- **A legacy**：原始按页/幻灯片切片，超限按句切（生产旧方案，1324 块）。
- **B fixed**：定长 300 字 + 100 字字符重叠（纯字符策略，不感知文档结构，2280 块）。
- **C structured_v1**：页眉页脚清理、标题与项目符号感知、语义 Child 检索、完整 Parent 回答、标题跨页继承、稳定内容 ID、跨版本精确去重（1076 块，去重 361）。
- 检索集：`tests/eval_retrieval.py` 20 个问题（领域级标签）。
- 检索链：Dense top20 + BM25 top20 + RRF，关闭 reranker；三方案均用 **dashscope qwen3.7-text-embedding 真实嵌入**。
- 运行：`python tests/compare_chunking.py --full-embeddings`（默认 proxy 模式复用同页向量，不调 API）。

## 关键结论（如实记录）

1. **Recall@5 未达 +10% 目标，原因是评测天花板而非切分**。三方案共同 miss 的 4 题（强制访问控制、资产识别与风险评估关系、IDS 部署、应急响应流程），逐一核验了检索结果——**三个方案召回的 top 内容全部包含正确答案**（如"强制访问控制"问题命中的块就含 Bell-LaPadula/Biba）。失败仅发生在领域标签：内容实际归在"信息安全支撑技术 / 物理与网络通信安全 / 业务连续性"下，而评测集期望"计算环境安全 / 安全工程与运营"。这正是旧评测文档已标注的跨知识域归属争议。要真正度量"正确知识块是否被召回"，需要建设知识点级 gold Chunk 集，领域级标签无法区分切分方案。
2. **fixed（B）是最差方案**：机械字符重叠导致 15.88% 内部重复、Top5 重复率 13%，Recall@1 还垫底（75%）。验证了"不要用机械字符重叠"的判断。
3. **structured（C）结构指标全面占优，检索与 legacy 等价**：标题 100%、重复 0.09%、块长上界 313（legacy 797）、Parent 完整（226 字）供回答。延迟最低（316ms，因块数少）。
4. **token 预算在 30% 边缘**：structured 上下文 978 字 vs legacy 754 字，约 +30%，因返回的是完整 Parent。这是"回答完整性"换"输入长度"的合理代价；若需收紧可调小 Parent 上限或回答时对超大 Parent 做截断。
5. **答案正确率 / 引用页码准确率未测**：需要真实 LLM 回答评测（`eval_intents.py` 覆盖意图路由，回答质量评测待建）。
