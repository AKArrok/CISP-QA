# 02 PRD — CISP 备考问答机器人

## 1. 目标用户与场景

备考 CISP 的本人。两个核心场景：

- **学中问**：看课件/刷题遇到不懂的概念，直接提问，得到基于官方课件的解释（带知识域出处）。
- **学后测**：让系统针对薄弱知识域出题，作答后即时判分、看解析，正确率数据沉淀为画像。

## 2. 功能需求

### F1 知识库问答（核心）

| 项 | 说明 |
|----|------|
| 输入 | 自然语言问题，支持多轮追问（"那 BCP 和 BIA 的区别呢？"） |
| 检索 | 混合检索：语义（doubao embedding）+ 关键词（BM25），RRF 融合，返回 top-k 知识块 |
| 回答 | 依据检索内容作答；每条回答末尾标注引用来源（知识域 + 课件名/页码或知识点总结） |
| 拒答 | 检索无相关内容时明确说"知识库中未覆盖"，禁止编造 |
| 范围 | 仅依据本地知识库，不联网 |

### F2 出题考核（核心）

| 项 | 说明 |
|----|------|
| 出题模式 | ① 随机练习：指定知识域或全部，从真题库抽题<br>② 薄弱强化：按画像加权，低正确率知识域出题概率高<br>③ AI 补充出题：某域真题抽完/不足时，由 LLM 参照该域知识块生成同风格单选题（标注"AI 生成"） |
| 题型 | 单选为主（CISP 客观题形态），兼容多选 |
| 作答 | Web 页面选择选项提交，逐题即时判分 |
| 解析 | 判分后展示：正确答案、题库自带解析（真题）或 AI 生成的解析、关联知识块（可点开看课件原文） |
| 题源标注 | 每题标注来源：`真题·700题库` / `真题·第X套` / `AI生成` |

### F3 薄弱点画像

| 项 | 说明 |
|----|------|
| 记录 | SQLite：每题作答记录（题目、知识域、对错、时间戳、来源） |
| 统计 | 按 10 个知识域输出：答题数、正确率；全局：累计答题数、总正确率 |
| 弱项判定 | 答题数 ≥ 3 且正确率 < 60% 的知识域标记为薄弱域 |
| 反哺 | "薄弱强化"出题模式按 `1 - 正确率` 加权抽样知识域 |
| 展示 | Web 面板统计页 + `GET /api/stats` 接口 |

### F4 会话与界面

- Web 面板两个页签：**问答**（聊天，SSE 流式）与 **刷题**（出题→作答→判分→解析→统计）。
- 问答多轮记忆（进程内，重启清空，与 AniRAG 一致）。

## 3. 非功能需求

| 项 | 指标 |
|----|------|
| 检索延迟 | 本地检索（dense+sparse）< 100ms |
| 端到端回答 | 首字 < 5s（受 LLM API 限制） |
| 题库解析正确率 | 结构化字段（题干/选项/答案）解析成功率 100% 可校验，解析失败题目落 `data/parse_failures.json` 人工核查 |
| 离线性 | 除 LLM/Embedding API 外全部本地（向量检索、BM25、题库、记录） |

| 资产 | 路径 | 处理 |
|------|------|------|
| V4.2 课件 PDF ×10 | `#5021 CISP.../CISP课件 V4.2/` | PyMuPDF 提取 → 按页分块 |

| 真题 docx ×6 + CISP216.docx | `CSIP试题/` | python-docx 解析为结构化题库 |

10 个知识域（打标用）：信息安全保障 / 信息安全监管 / 信息安全支撑技术 / 物理与网络通信安全 / 计算环境安全 / 软件安全开发 / 信息安全评估 / 信息安全工程与运营 / 业务连续性 / 信息安全管理。

## 5. Out of Scope（本期不做）

- 多用户 / 登录系统
- 移动端
- 完整 FSRS 间隔重复算法（用正确率画像的简版）
- 主观题（案例分析）判分
- 扫描版 PDF 的 OCR 深度处理（仅检测空页并记录）
